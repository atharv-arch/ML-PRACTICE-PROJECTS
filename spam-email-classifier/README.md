# 📧 Email Spam Classifier

## 🚀 Overview

This project is a Machine Learning-based Email Spam Classifier that detects whether a message is **Spam** or **Not Spam (Ham)**.

It uses Natural Language Processing (NLP) techniques and a Naive Bayes model to classify messages with high accuracy.

---

## 🧠 Features

* Text preprocessing (lowercase, stopwords removal, stemming)
* Feature extraction using CountVectorizer
* Model training using Multinomial Naive Bayes
* Achieved ~97% accuracy

---

## ⚙️ Tech Stack

* Python
* Pandas

* NLTK
