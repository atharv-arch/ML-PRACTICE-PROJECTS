# Phishing Website Detection

## Project Overview
This project detects whether a website URL is safe or phishing using Machine Learning.

## Features Used
- URL Length
- HTTPS presence
- Number of dots
- Number of hyphens
- Number of slashes
- Presence of @ symbol

## Model Used
- Random Forest Classifier
- Logistic Regression
- SVM

## Accuracy
- Random Forest: 83%
- logistic regression : 83.7%
- svm : 82%

## Workflow
Raw URLs → Feature Engineering → Model Training → Prediction

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Google Colab
